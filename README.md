# Food Ordering Behaviour & Consumer Trends Analysis

A comprehensive data analytics project analyzing customer ordering habits, revenue drivers, cuisine preferences, and peak operational times using Tableau and Flask.

---

## Key Highlights
- **Revenue by Cuisine:** Detailed breakdown of top-earning cuisines (Desserts, Fast Food, North/South Indian, Chinese, Biryani).
- **City Performance:** Order volume and customer distribution across major metropolitan cities.
- **Ordering Patterns:** Day-type and time-of-day heatmaps tracking peak demand.
- **Consumer Mood & Spending:** Correlation analysis between hunger level, mood, and average order value.

---

## Tech Stack
- **Data Analytics & Visualization:** Tableau Desktop (`.twbx`)
- **Web Framework:** Python, Flask
- **Frontend:** HTML5, Jinja2 Templates
- **Data Source:** CSV Dataset (`food_ordering_behavior_dataset.csv`)
